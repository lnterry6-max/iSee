# iSee — Dedicated Photography, Reimagined

**An independent product and engineering portfolio concept.** Not affiliated with, sponsored by, or endorsed by Apple.

iSee imagines two focused cameras:

| | iSee Air | iSee |
|---|---|---|
| Audience | Everyday photography | Creators and enthusiasts |
| Form | Pocketable, lightweight | Larger, more tactile |
| Optics | Integrated fixed lens | Advanced integrated fixed lens |
| Controls | Touch + essentials | Touch + customizable dials |
| Concept price | $399–$499 | $799–$999 |

**cameraOS** imagines a distraction-free camera interface. **Focus Intelligence** explores subject isolation and optional AI-assisted background-person removal. The demonstration is only a visual simulation; no real AI image processing is implemented. Untouched originals would be preserved.

## Local development

No dependencies or build tooling are required. Clone this repository and open `index.html` in any modern browser, or start a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deployment

The GitHub Actions workflow runs static-link and JavaScript checks on `development` and pull requests. A push to `main` attempts to publish the site through GitHub Pages. If Pages is not automatically enabled, select **Settings → Pages → Build and deployment → GitHub Actions**.

## Original artwork

Product illustrations are custom SVG concept renders. They are not real photographs of manufactured devices. The visual design should be iterated as original iSee industrial design concepts become available.
